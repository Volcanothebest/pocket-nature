# 口袋自然 Pocket Nature · v1.0

山水有清音 —— 给去不了远方的人，一段随身的自然声音疗愈。
A pocket-sized nature sound practice for commutes, lunch breaks and sleepless nights.

## 运行 / Run
直接用浏览器打开 `index.html`（`img/` 文件夹需与它放在一起）。所有声音由 Web Audio 实时合成，无需联网下载音频。
Open `index.html` in any modern browser. Keep `img/` next to it.

## 功能 / Features
- 8 个场景，按时段自动推荐：晨起唤醒、通勤路上、片刻小憩、临场静心、午休片刻、独处时刻、睡前放空、夜里醒来
- 9 种合成地貌声音与混音器；点击 / 拖动画面触发雨滴、溪石、冰晶、古筝、鸟鸣（五声音阶）
- 练习前后测评（情绪、心里天气、身体感受），按情绪给出不同引导，结束时用温柔语言反馈变化
- 吸 4 呼 6 的海浪呼吸引导；中英双语；参考文献按证据等级 A–D 展示
- 隐私：身体感受与分数只存本机；匿名统计默认关闭
